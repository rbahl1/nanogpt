A small GPT that has only ever read Lean 4. Give it the header of a declaration and it writes the rest. Each message is a separate declaration: the model has no memory of earlier turns. It runs entirely in your browser.

Enter sends, Shift+Enter adds a line. Lean abbreviations work: \and ∧, \or ∨, \not ¬, \to →, \iff ↔, \< ⟨, \forall ∀, \exists ∃, \a α.
